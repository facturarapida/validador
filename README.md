# Validador DNI / NIF / CIF de España (gratis)

Valida al instante DNI, NIE y CIF españoles **100% en tu navegador**: no envía ningún dato a ningún servidor.

## Herramienta gratuita
- **Validador DNI/NIF/CIF gratis (online):** https://facturarapida.github.io/validador/
- DNI/NIE: módulo 23 con tabla oficial `TRWAGMYFPDXBNJZSQVHLCKE`
- CIF/NIF de empresas: algoritmo AEAT (pares + impares × 2, módulo 10)
- Uso típico: validar el NIF de un cliente **antes de emitir la factura**

## Uso
1. Abre https://facturarapida.github.io/validador/
2. Escribe el número (ej. `23914180E`, `B12345674`) y pulsa **Validar**
3. Resultado: VALIDO / INVÁLIDO + letra o dígito de control esperado
